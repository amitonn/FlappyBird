# FlappyBird

A simple implementation of the classic Flappy Bird game. This project recreates the addictive mechanics and retro style of Flappy Bird, allowing you to play, modify, and learn from the source code.

## Features

- Classic Flappy Bird gameplay: Tap to flap and avoid obstacles
- Score tracking and high score saving
- Pixel art graphics and sound effects
- Customizable game parameters (speed, gravity, etc.)
- Simple code structure for learning and experimentation

## Getting Started

### Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/amitonn/FlappyBird.git
   cd FlappyBird


### Running the Game
To run the game, execute the `flappybird.exe` file:

1. Navigate to the directory containing `flappybird.exe`.
2. Run the executable:
    ```sh
    ./flappybird.exe
    ```

Ensure all required assets are in the same directory as the executable.

## Game Controls

- **Space**: Flap
- **Esc**: Exit the game
